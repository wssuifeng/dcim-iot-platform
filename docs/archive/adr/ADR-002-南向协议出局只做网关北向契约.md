# ADR-002: 南向协议出局，只做网关北向契约

日期：2026-08-27
状态：已接受（阶段二路线）

## 背景

真实 DCIM 架构中，现场设备（UPS/PDU/空调/温湿度）通过 RS485/Modbus、SNMP、BACnet 等南向协议接入采集网关；网关做协议翻译，向北用 MQTT/HTTPS 推送统一 JSON 给云平台。平台永远不直接面对协议动物园。

## 决定

本平台**不实现任何南向协议驱动**，只定义网关级北向契约：

- 网关凭证（accessKey/secret）+ 独立鉴权过滤器（与用户 JWT 分离）
- `POST /ingest/samples` 批量 JSON：deviceId、pointCode、值、设备时间戳、seq
- 幂等键（deviceId+pointId+seq）去重，支持断网补传（迟到但有序）
- 第一期 HTTP 实现，MQTT 适配器留接口位

## 放弃了什么

- Modbus/SNMP/BACnet/DL645 解析器。协议翻译是网关硬件的职责，平台侧模拟它没有价值且无法验证正确性。

## 后续

v1.0 用户态 `device-data` API 随阶段二退役；仿真引擎（ADR-003）以"官方内置诚实网关"身份走同一条契约灌数。
