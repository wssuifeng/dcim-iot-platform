# ADR-009 自定义报文映射与零散设备接入

- 状态：已接受（2026-09-01）
- 关联：ADR-005（机房即接入主体）/ ADR-006（首包自动注册）/ ADR-008（开放通道边界）；用户需求（2026-09-01 对话，"自定义报文结构模型对接云平台数据模型，用户手动填映射，平台自动转译"）
- 实施：V25 + `ingest/template/PayloadTranslationEngine` + `ingest/service/IngestPayloadMappingService` + `ingest/http/PayloadMappingController` + 前端 `views/ingest-mapping/`

## 一、背景

开放通道（TB token / MQTT 子凭证）解决了"传输与鉴权"，但报文**内容**仍是平台方言（TB 三形态 / 标准 batch）。自带网关或固件的零散直连设备说不了这两种方言时，数据收得到却读不懂。用户明确不做自动猜字段，要求：**报文展示给用户 → 用户手动把报文字段对应到平台数据模型 → 平台自动转译**。

## 二、决策

### D1 模板挂机房，不挂凭证、不做内容嗅探

模板归属 `cloud_room_id`，对该机房内全部开放通道凭证生效。理由：归属链与 ADR-005 同构（凭证→机房→模板池）；凭证与机房 1:1，挂机房使"一个机房多个子凭证"共享模板。报文→模板的路由靠**特征匹配**（用户 2026-09-01 定案：一类设备有特征，模板内保留特征规则），不做内容嗅探（歧义大）。

### D2 特征匹配三操作，空规则不匹配

规则数组 `[{"path","op","value"}]`，op 仅 `eq`/`contains`/`exists`；**全部命中**才路由，多条模板按 id 升序取第一个"特征全中且转译出 ≥1 条采样"的模板。空规则列表视为不匹配（防 catch-all 误路由），保存时强制 ≥1 条。

### D3 转译口径

- **路径语法**：点路径 + 数组下标（`data.items[0].temp`），刻意不支持脚本/正则/函数（安全边界，避免做成自由 DSL 无底洞）。
- **设备编码**：报文路径提取或固定值，二选一（保存校验强制）。
- **采样时间**：`sampleTimePath` 解析毫秒/秒级时间戳（<1e11 按秒），缺省=服务器接收时刻。
- **数值**：数值直取 / 布尔 0-1 / 可解析数字的字符串自动转；每映射可配缩放系数 scale（raw × scale）；不可解析字段跳过不报错。
- **批内上限** 200 条，与 ingest 同口径。

### D4 转译产物进传输无关核心

`tryTranslate` 产出 `IngestSampleBatchDTO` 直接调 `processSamples`——机房归属校验、首包自动注册、类型推断、无 seq 幂等降级（`deviceCode+pointCode+sampleTime`）、告警评估全部复用，零新链路。**TB 兼容层可视为本功能的第一个内置模板**，未来可收敛（当前保留独立实现）。

### D5 通道挂载：回退语义

两条开放通道均为"标准解析优先，失败回退映射"：

- MQTT `dcim-open/+/samples`：标准 batch 解析（含校验）失败 → `tryTranslate`；转译命中走核心，未命中留存原始报文并审计拒收。
- HTTP `/api/v1/{token}/telemetry`：TB 三形态解析失败 → `tryTranslate`；未命中留存原始报文并维持原 422（TB SDK 语义不变，`test_connection` 空报文探测仍 200）。

### D6 原始报文留存：每凭证仅最新一条

`ingest_raw_message` 唯一键 `credential_id`，新报文 UPSERT 覆盖（用户定案："只留一条就够了"）。Retained Message 说明：broker 保留消息仅在新订阅建立时投递，标准无主动查询接口，故平台自存一行充当"配置参照物"；MQTT 订阅建立时 broker 自动推 retained 报文，两个机制互补。

### D7 dry-run 预览必配

映射配置页提供 dry-run：模板草稿（可不落库）对原始报文做匹配+转译，展示命中模板/设备编码/采样项/说明，确认后再保存（用户定案："填完之后可以测试"）。dry-run 不落采样。

### D8 放弃项

- 不做用户自定义脚本转换（安全 + 复杂度）。
- 不做一报文多子设备数组展开（遇到时 TB 兼容层已覆盖）。
- 不做每设备独立凭证（现有"零散机房 + 机房凭证"已覆盖，设备级 key 增益仅泄露隔离，单租户口径下不值得动 UNIQUE 约束与归属链）。
- 不做自动字段猜测（用户明确选择手动映射）。

## 三、后果与影响面

- V25 两表：`ingest_payload_mapping`（模板，feature_json/mappings_json 结构化序列化）、`ingest_raw_message`（留存）。
- `IngestMqttListener` / `TelemetryCompatController` 各加一次回退分支；`IngestMqttListener` 构造器新增 `IngestPayloadMappingService` 依赖。
- 前端新增 ADMIN 侧栏"零散设备接入"（`/ingest-mapping`，navigationOrder 55）。
- 网安口径：模板路径解析为纯读操作无注入面；`feature_json/mappings_json` 仅 ADMIN 可写；开放通道整体仍按 ADR-008 纳入后期专项。
