## 四、阅读建议

### 初学者推荐阅读顺序

1. **项目总览** — 了解项目整体架构和目标
2. **entity 模块** — 理解数据模型，这是所有业务的基础
3. **dto 模块** — 学习数据传输对象的设计与校验
4. **mapper 模块** — 学习数据库交互方式
5. **service 模块** — 掌握业务逻辑的组织方式
6. **service/impl 模块** — 深入核心业务实现细节
7. **controller 模块** — 了解如何对外暴露接口
8. **common 模块** — 学习统一响应封装
9. **config 模块** — 了解框架配置管理

### 按场景查阅

| 场景 | 推荐文档 |
|------|----------|
| 搭建开发环境 | 项目总览 → 环境配置指南 |
| 理解数据模型 | 实体类文档 → 数据传输对象文档 |
| 编写新接口 | Controller接口文档 + 业务接口文档 + 数据访问层文档 |
| 添加新实体 | 实体类文档 + 数据传输对象文档 + 数据访问层文档 + 业务接口文档 |
| 统一响应格式 | 通用基础设施文档 |
| 启用分页功能 | 框架配置文档 |
| 理解业务实现 | 核心业务实现文档 |
| 排查启动问题 | 项目总览 → 已知问题 |
