## 2. 北向契约（机器侧，平台承诺面）

### 2.1 通道总表

| 通道 | 端点 / Topic | 鉴权 | 语义 |
|------|-------------|------|------|
| HTTP HMAC | `POST /api/ingest/samples` | `Authorization: Gateway {AK}:{sha256(SK+rawBody)}` | 同步逐条结果 |
| MQTT HMAC | 发布 `dcim/{accessKey}/samples`（QoS 1） | broker dynamic-security + 报文验签 | 报文 `{"signature","batch"}` |
| MQTT 遗嘱 | `dcim/{accessKey}/lwt` | 同上 | 网关离线即时告警（只触发，不挂数据） |
| TB 兼容 | `POST /api/v1/{token}/telemetry`（context-path 之外） | token（40-hex，无逐请求签名） | 四形态解析（ADR-008） |
| MQTT 子凭证 | 发布 `dcim-open/{mqttUsername}/samples` | broker 连接层账号密码 | 标准解析失败走映射回退 |
| 心跳 | `POST /api/ingest/heartbeat` | Gateway 签名 | 网关保活恒走 HTTP（FR-C9-01） |
| 清单上报 | `POST /api/ingest/inventory` | Gateway 签名 | 设备清单建档同步（FR-C5-05） |
| 阈值导出 | `GET /api/ingest/export/thresholds` | Gateway 签名 | 网关本地告警判定的配置源（含机房目录） |

### 2.2 HMAC 签名规范

- 算法：`sha256(SecretKey + rawBody)`，rawBody 为**原始请求字节**（不得重序列化后签名）；摘要十六进制，以 `GatewayAuthenticationFilter` 实现为准。
- MQTT envelope：`{"signature": "...", "batch": [...]}`；**现状缺陷**：平台验签对解析后子树重序列化（W-011），对网关序列化差异敏感——修复设计（FR-B-011）：envelope 的 `batch` 改字符串字段，网关对自身原始串签名，破坏性变更走 §5 演进流程。
- 防重放（FR-B-021 设计预留）：增 `X-Gw-Timestamp` 头参与签名，±300s 窗口；心跳报文纳入验签。

### 2.3 上报契约（IngestSampleItemDTO，HTTP/MQTT HMAC 共用）

| 字段 | 必填 | 约束 |
|------|------|------|
| deviceCode | 是 | ≤50 字符，`[A-Za-z0-9_-]`；未知编码触发首包自动注册（凭证开关） |
| pointCode | 是 | ≤50 字符，`[A-Za-z0-9_-]`；须为平台指标字典已绑定指标（自动注册场景可推断） |
| value | 是 | BigDecimal 采样值 |
| sampleTime | 是 | 设备侧时间；**晚于平台时间 +5 分钟拒绝；早于按断网补传合法接收** |
| seq | HMAC 通道必填 | 网关侧单调递增；QoS1 重发保持不变；开放通道无此字段 |

- 批量 ≤200 条（`@Size(max=200)`），**逐条独立事务，部分成功合法**。
- 响应 `IngestResultVO`：`accepted`（成功数）/ `duplicated`（幂等跳过数）/ `failed`（失败数）/ `failures[]`（每项：请求下标 index、错误码 errorCode、错误信息 message）。QoS1 重发计入 duplicated 不报错。

### 2.4 幂等与去重语义

- 键：`sha256(deviceCode:pointCode:seq)`；开放通道降级 `deviceCode+pointCode+sampleTime`。
- 窗口 7 天（ingest_dedup 定时清理）；**窗口外重发会重复落库**——网关侧 seq 不得清零复用（清零须更换 deviceCode 或等待平台 seq 纪元机制，W-012 文档化去向）。

### 2.5 开放通道与映射回退

- TB 四形态（ADR-008）：T1 简单对象 `{"temperature": 22.5}`；T2 时间戳对象 `{"ts": 1690000000000, "values": {"temperature": 22.5}}`；T3 数组（T2 元素列表）；E1 `device` 字段多子设备扩展（形态细节以 TelemetryCompatController 与 ADR-008 为准）。T1/T3 无显式设备时用凭证 `telemetry_default_device`。
- 映射回退（两条开放通道同语义）：标准解析失败 → 按机房映射模板特征匹配（eq/contains/exists，全命中才路由）→ 字段路径转译（含 scale）→ 汇入同一条核心链路；未命中 → 原始报文留存（每凭证最新一条，表 ingest_raw_message）。
- 管理接口（ADMIN，`/api/ingest/` 下）：映射模板 CRUD、`POST /dry-run`（样例报文试算，不落库）、`GET /raw-message`（留存查询）。

### 2.6 错误语义

- 统一响应 `Result<T>` + `ResultCode` 枚举扩展（**禁止硬编码 HTTP 状态码**）；非法签名/越权归属拒绝、批量超限、时间边界违反均以结构化错误码返回，逐条失败见 `failures[]`。
- 通道级流量可观测：`GET`（ingest-metrics）返回 accepted/failed/deduped 通道指标（TB 通道埋点缺口 = FR-B-010）。

## 3. 用户态 API 契约原则

- **统一响应**：`Result<T>`/`ResultCode`；**分页**：`size ≤ 100, current ≥ 1`（PaginationUtils 校验）。
- **RBAC 边界**（以各控制器 Swagger 注解为准，下表为注解归纳）：

| 控制器族 | 权限（注解原文归纳） |
|---------|---------------------|
| 机房管理 /cloud-rooms | ADMIN 写，已认证用户读 |
| 告警事件 /alarm-events | ADMIN/OPERATOR 处理，已认证按范围读 |
| 指标采样 /metric-samples | ADMIN/OPERATOR 写，已认证按范围读 |
| 设备指标绑定 /device-points | ADMIN 写，已认证按范围读 |
| 用户管理 /users | 仅 ADMIN |
| 平台级指标资源 /platform | ADMIN 专属 |
| 审计日志 /audit-logs | 查询 ADMIN/OPERATOR；清理仅 ADMIN |
| 告警通道 /webhook-channels | ADMIN-only（含测试发送） |
| 零散设备接入 /ingest 映射 | ADMIN（前端路由同口径） |
| 认证 /auth | 公开（登录/注册）+ 已认证（登出） |
| 仪表盘/对比/最新值/通知 | 已认证按数据范围 |
| 设备/类型/模版/指标字典等管理接口 | 以 Swagger 注解为准 |

- **数据范围**：读接口按授权范围过滤（机房维度）；越权 100% 拒绝（FR-C11-02）。
- **审计**：关键写操作 `@AuditLog` 留痕（结构化入 sys_audit_log）。
- **WebSocket**：STOMP 端点（`/ws`，鉴权拦截器校验 JWT），用户隔离队列推送站内通知与告警弹窗事件。
- **限流**：IP 限流 60s/1000 默认（机器通道凭证维度限流为 FR-B-026 修复项）。

## 4. 不支持设备类型清单（FR-C15-04，本节为需求落点）

| 类别 | 设备/报文形态 | 接入路径 |
|------|-------------|---------|
| **直连支持** | MQTT JSON 报文；TB 生态组件（T1/T2/T3/E1）；自定义 JSON（映射模板可转译） | 四通道直接接入 |
| **必须前置协议网关** | 仅支持 Modbus RTU/TCP、SNMP、BACnet、电力 645 等南向协议的设备 | 第三方协议转换网关（Modbus→MQTT/JSON 等）翻译后按标准通道接入；平台不实现南向协议（ADR-002） |
| **必须前置协议网关（二进制）** | Modbus 透传帧、hex/base64 二进制上报 | 同上；平台映射模板仅支持 JSON 文本（FR-B-009），二进制映射扩展属定义变更事项（未裁决不做） |
| **不支持** | 平台侧南向采集、协议插件框架（非目标）；设备侧零配置即插即用发现（非目标） | 无接入路径，明确拒绝 |

## 5. 契约演进与兼容策略

- 北向契约**新增字段向后兼容**（网关可不发送）；**破坏性变更**（如 FR-B-011 的 batch 字符串化、FR-B-021 的新增签名头）必须：决策日志留痕 → 双格式过渡期（新旧并存）→ 仿真器同步升级 → 版本化公告。
- seq 语义、时间边界、幂等窗口为本契约的**正确性基线**，变更走系统定义变更流程。
- 用户态接口演进以 Swagger 注解为准实时生效；文档性变更随本包 `_中控.md` 回写。
