## 二、开源项目清单

### A. 网关/采集器（真实客户端候选）

| 项目 | 协议能力 | 用法 |
|------|---------|------|
| [Node-RED](https://nodered.org/)（+node-red-contrib-modbus） | Modbus/MQTT/HTTP/SNMP 节点生态 | ✅ 已用于验证 B；用户真实组网胶水层 |
| [ThingsBoard IoT Gateway](https://github.com/thingsboard/thingsboard-gateway) | Modbus/OPC-UA/BACnet/MQTT/CAN/ODBC/SNMP/REST | 北向为 TB 专有；若加"TB 兼容设备 API"可白接生态（P2 候选） |
| [Telegraf](https://github.com/influxdata/telegraf) | modbus/snmp/mqtt 输入、http/mqtt 输出 | 生产级采集器；http 输出无逐请求 HMAC 能力（契约限制，见 01-S8-5 设计注记） |
| [NUT](https://networkupstools.org/) | UPS 事实标准 | P1 数据源（NUT→MQTT 桥） |
| [Home Assistant](https://www.home-assistant.io/) / [ESPHome](https://esphome.io/) | 传感器生态 | P1 MQTT payload 兼容 |

### B. 协议仿真器/测试床（南向验证）

| 项目 | 说明 | 状态 |
|------|------|------|
| [pymodbus](https://github.com/pymodbus-dev/pymodbus) | 事实标准 Python Modbus 栈 | ✅ 已用于验证 A |
| [Diagslave](https://www.modbusdriver.com/diagslave.html) | 命令行 slave 仿真 | 候选 |
| [ModbusPal](https://sourceforge.net/projects/modbuspal/) / [ModbusSlaveSimulation](https://github.com/GitHubDragonFly/ModbusSlaveSimulation) | GUI 多从站仿真 | 候选 |
| snmpsim / bacnet-stack | SNMP/BACnet 仿真 | 平台扩协议时启用 |

### C. 对标平台（定位参照，不对标广度）

| 平台 | 关系 |
|------|------|
| ThingsBoard / JetLinks | 通用 IoT 平台；取批量供给痛点教训（issue #7608 等） |
| Rapid SCADA / SCADA-LTS / FUXA | 工控 SCADA 可视化方向，与动环告警闭环不冲突 |
| openDCIM（维护者退休）/ NetBox | DCIM 资产文档；"活数据+告警"象限空白即本项目站位 |

### D. 通知/运维生态（G2/G3 的实现参照）

ntfy（自建推送事实标准，一条 curl）、Gotify、Apprise（多通道聚合）、钉钉/企微/飞书自定义机器人 webhook、PagerDuty 式电话升级。
