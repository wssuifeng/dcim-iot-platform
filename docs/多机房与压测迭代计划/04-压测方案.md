# 阶段七 · 压测方案

> 执行前提：S1–S5 全部完成；平台（8081）、前端（5174）、仿真器（8090）运行中；MySQL/Redis 健康基线已记录。

## 1. 档位定义

| 档位 | 机房数 | 设备/机房 | 点数/设备 | reportInterval | 理论样本量 |
|------|--------|----------|----------|----------------|-----------|
| L0 基线 | 1 | 19（现网） | 3–5 | 60s | ~40 样本/min |
| L1 常态多机房 | 2 | 20 | ~4 | 60s | ~160 样本/min |
| L2 高频 | 2 | 20 | ~4 | 10s | ~960 样本/min |
| L3 高压 | 4 | 20 | ~4 | 5s | ~3840 样本/min |
| L4 风暴 | 6 | 20 | ~4 | 2s | ~14400 样本/min |

- 设备构成为套件默认配比（8 温湿度/2 UPS/4 电表/3 空调/2 漏水 + 1 补位），点均 ≈4（温湿度 2、UPS 5、电表 2、空调 2、漏水 1 加权）；
- 死区/越限额外上报按 +20% 估算（物理引擎驱动下模拟量死区命中频繁）；
- L4 为上限探索档：若 L3 已现劣化（P95 > 500ms 或错误率 > 0.1%），记录现状后止步，不强行升档。

## 2. 执行步骤（每档位）

1. **建档**：压测机房命名 `LOAD-1..n`（与常态机房隔离），创建机房取凭证，仿真器建网关 + 设备套件，启动；
2. **预热 3min**：等首包注册、模版绑定、阈值同步完成；确认平台侧各机房设备清单正确；
3. **稳定窗口 15min（L4 为 30min）**：期间不进行任何演练操作；
4. **采样**（每 60s 一次，脚本轮询落 CSV）：
   - 仿真器：`GET /api/sim/load-stats`（每网关 qps/成功率/p95）；
   - 平台：`GET /api/observability/ingest-metrics`（accepted/rejected/deduped/直方图）；
   - JVM：平台进程 `jstat -gcutil <pid> 60s`（或 Actuator `/api/actuator/health` + 进程 RSS）；
   - MySQL：Druid 监控页 SQL 耗时 TOP（或 `SHOW GLOBAL STATUS LIKE 'Questions'` 差分）；
5. **功能抽检**（稳定窗口内一次）：
   - 触发一个机房的环境演练（如负载激增）→ 告警在 2 个上报周期内到达；
   - 平台前端跨机房检索页加载正常（高写入下查询不被拖垮）；
   - WebSocket 告警推送延迟目测正常；
6. **降档收尾**：网关停 → 平台侧该机房网关离线告警触发 → 重启 → 恢复闭环（同时验证高压下离线检测任务不误报）。

## 3. 通过判据

| 指标 | 判据 |
|------|------|
| 错误率 | 各档位 5xx = 0；4xx 仅限预期内（如演练制造的越权/不存在设备） |
| 服务端批次延迟 | L3 及以下 P95 < 500ms；L4 P95 < 1s |
| 客户端上报延迟 | p95 < 服务端判据 × 2（含网络与排队） |
| 数据完整性 | 抽检任一设备 10min 窗口样本数 ≥ 理论值 × 90%（死区丢失属正常） |
| 告警时效 | 演练注入 → 告警可见 ≤ 2 上报周期 |
| 资源 | 平台 JVM 老年代稳定（无持续增长）；MySQL 连接池无耗尽告警 |
| 幂等 | deduped 计数 > 0 且无重复样本落库（抽检 deviceCode+pointCode+sampleTime 唯一） |

## 4. 观察项（不判失败，记入报告）

- metric_sample 表容量增速与 TTL 清理滞后量；
- ingest_dedup 表行数走势与清理任务节奏；
- MQTT vs HTTP 传输在 L3/L4 的差异（各档位至少一个网关走 MQTT）；
- 告警评估在样本洪峰下的耗时占比（慢批次 WARN 日志频率）；
- 离线检测/网关检测定时任务在高压下是否出现误报。

## 5. 数据清理

压测完成后：`LOAD-*` 机房默认**整体删除**（机房级联删凭证与设备；采样/告警数据按平台既有级联与 TTL 处理），保留与否由用户在报告评审时决定——脚本先导出机房清单与统计快照再删。

## 6. 工具与脚本

- 采样脚本：仓库 `docs/多机房与压测迭代计划/scripts/load-probe.py`（轮询两端指标落 CSV，随 S6 任务卡提交）；
- 采样期环境模拟参数：全部机房固定种子（环境引擎确定性），避免物理事件与压测变量混淆；演练抽检只用一个标记机房。
