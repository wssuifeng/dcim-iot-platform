# 冷库温湿度监控平台 — 产品化规划文档

> **基于 IoT-Platform v0.0.1-SNAPSHOT 升级** | 2026-06-24

---

## 一、项目定位

**一句话**：为小型生鲜店/餐饮店/药店提供轻量级冷库冷柜温湿度云端监控，替代昂贵的工业动环方案和无远程功能的单机记录仪。

**目标用户**：小餐饮连锁(3-10个冷柜)、社区生鲜店、小型药店、冷链运输小微运营商

**核心痛点**：
- 工业动环方案太贵(动辄万元起步)，小商户用不起
- 单机温度记录仪只能本地看，不能远程，不能历史回溯
- 超温发现不及时，食材/药品损坏才知道
- 多个冷柜分散在不同门店，无法统一管理

**面试故事**："大型冷链方案太贵，小记录仪没远程管理，我做的是填中间市场空白的产品"

## 二、需求分析

### 2.1 用户角色

| 角色 | 权限 | 核心操作 |
|------|------|---------|
| ADMIN(店长/老板) | 全部 | 管理设备、查看大屏、导出报告、配置告警规则 |
| OPERATOR(店员) | 查看+确认 | 查看实时数据、确认告警 |
| VIEWER(审计) | 只读 | 查看历史数据和告警记录 |

### 2.2 用户故事

1. 店长打开手机看到1号冷库温度8.2℃超限，红色告警弹窗
2. 店长查看过去7天温度曲线，发现每天下午2点温度都会偏高
3. 店长导出本月温湿度报告，提交给食药监检查
4. 温度超过8℃持续5分钟，系统通过大屏弹窗/WebSocket通知店长，并记录通知日志
5. 新冷柜到货，店长在后台添加设备，5分钟完成接入；扫码添加作为后续移动端能力预留

### 2.3 功能清单

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | MQTT设备接入 | 冷库/冷柜传感器通过MQTT上报温湿度数据 |
| P0 | 实时温湿度监控 | 大屏实时展示多设备温湿度，10秒刷新 |
| P0 | 温度阈值告警 | 超温/超湿自动告警，支持5级告警+去重+升级+化霜延时告警 |
| P0 | 历史数据查询 | 按时间段查询温度曲线 |
| P0 | 告警通知 | 告警弹窗 + 通知日志 |

| P2 | 超温持续时长统计 | 记录每次超温的持续时长 |

## 三、技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| MQTT Broker | Mosquitto 2.x | 轻量、Docker一键部署、免费 |
| MQTT客户端(Java) | Spring Integration MQTT | Spring生态原生支持，和SB4兼容 |
| MQTT客户端(Python) | paho-mqtt 2.x | 成熟稳定，教程多 |
| 数据采集 | Python + psutil + 正弦波模拟 | 无需硬件，数据有真实感 |
| 大屏可视化 | ECharts 5 + vue-echarts | 项目已有依赖，复用 |
| 部署 | Docker + Nginx | 云服务器一键部署 |

**技术边界**：除新增 Mosquitto 作为 MQTT Broker 外，不改数据库选型(MySQL 9继续用)、不新增核心存储中间件、不引入复杂SaaS基础设施。

```python
# data_generator.py
import random
import math
from datetime import datetime

def generate_temp(device, hour_of_day, elapsed_minutes):
    """生成温度数据：基于正常范围 + 昼夜波动 + 随机噪声 + 偶发异常"""
    low, high = device["temp_range"]
    mid = (low + high) / 2
    amplitude = (high - low) / 4

    # 昼夜波动：下午2点最高
    cycle = math.sin(2 * math.pi * (hour_of_day - 8) / 24) * amplitude * 0.3

    # 随机噪声
    noise = random.gauss(0, 0.3)

    # 偶发异常：2%概率温度漂移（模拟门没关好/压缩机故障）
    anomaly = 0
    if random.random() < 0.02:
        anomaly = random.uniform(3, 8)  # 温度上升3-8℃

    temp = mid + cycle + noise + anomaly

    # 冷藏车特殊：5%概率开门卸货，温度飙升
    if device["type"] == "COLD_TRUCK" and random.random() < 0.05:
        temp += random.uniform(4, 10)

    return round(temp, 1)

def generate_humidity(device, temp, base_temp):
    """湿度与温度负相关"""
    low, high = device["humidity_range"]
    mid = (low + high) / 2
    temp_diff = temp - base_temp
    humidity = mid - temp_diff * 2 + random.gauss(0, 2)
    return round(max(20, min(95, humidity)), 1)
```

```python
# main.py
import json
import time
import paho.mqtt.client as mqtt
from datetime import datetime
from config import DEVICES, MQTT_BROKER, MQTT_PORT, REPORT_INTERVAL
from data_generator import generate_temp, generate_humidity

client = mqtt.Client(mqtt.CallbackAPIVersion.VERSION2)
client.connect(MQTT_BROKER, MQTT_PORT, 60)
client.loop_start()

print(f"冷库模拟脚本启动，{len(DEVICES)}个设备，每{REPORT_INTERVAL}秒上报一次")

start_time = time.time()
while True:
    elapsed = (time.time() - start_time) / 60  # 分钟
    hour = datetime.now().hour

    for device in DEVICES:
        temp = generate_temp(device, hour, elapsed)
        base_temp = sum(device["temp_range"]) / 2
        humidity = generate_humidity(device, temp, base_temp)

        payload = {
            "deviceCode": device["code"],
            "timestamp": datetime.now().isoformat(),
            "metrics": {
                "cold_temp": temp,
                "cold_humidity": humidity
            },
            "battery": random.randint(70, 100),
            "signal": random.randint(-80, -50)
        }

        topic = f"coldmonitor/{device['code']}/data"
        client.publish(topic, json.dumps(payload), qos=1)
        print(f"[{datetime.now().strftime('%H:%M:%S')}] {device['code']}: {temp}℃ / {humidity}%")

    time.sleep(REPORT_INTERVAL)
```
