## 1. 页面 1：设备管理 `device`

**路由** `/devices` · **API** 新建 `api/device.js`

**后端接口**（DeviceController）：
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/devices/page?current=&size=&status=&name=` | 分页+筛选 |
| POST | `/devices` | 新增（body: Device） |
| PUT | `/devices/{id}` | 更新 |
| DELETE | `/devices/{id}` | 删除（确认弹窗） |
| PUT | `/devices/{id}/status?status=` | 切换状态 0/1/2 |
| PUT | `/devices/{id}/alert-config` | 告警规则配置（body: AlertRuleConfig） |

**实体 Device**：`id, deviceName, deviceCode, typeId, status(0/1/2), location, ipAddress, lastOnlineTime, createTime, alertRuleConfig(JSON)`

**依赖**：新建 `api/deviceType.js`（只需 `getDeviceTypes` → GET `/device-types`），供设备表单的类型下拉。

**UI 文档**：`UI-04-DevicePage.md` 含完整 §6 实现代码，直接参照。

## 5. 页面 5：用户管理 `user`

**路由** `/users` · **API** 新建 `api/user.js` · **权限** 仅 ADMIN（菜单 `v-if` 隐藏）

**后端接口**（SysUserController）：
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/users/page?current=&size=&keyword=` | 分页+搜索 |
| POST | `/users` | 创建（含 password 字段） |
| PUT | `/users/{id}` | 更新（仅 nickname/role 可改） |
| DELETE | `/users/{id}` | 删除 |
| PUT | `/users/{id}/password` | 重置密码（body: `{newPassword}`） |
| PUT | `/users/{id}/status?status=` | 启用(0)/停用(1) |

**实体 SysUser**：`id, username, nickname, role` — **注意** `password/status/loginFailCount/lockTime` 被 `@JsonIgnore` 不返回。

⚠️ **已知限制**：由于 `status` 被 `@JsonIgnore`，表格无法显示"当前状态"列。创建用户时含密码字段（8-32位大小写+数字），编辑时不改 username。重置密码走独立弹窗。

## 6. 页面 6：审计日志 `audit-log`

**路由** `/audit-logs` · **API** 新建 `api/auditLog.js`

**后端接口**（SysAuditLogController）：
| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/audit-logs/page?current=&size=&userId=&operation=&startTime=&endTime=` | 多条件分页 | ADMIN+OPERATOR |
| DELETE | `/audit-logs/cleanup?beforeTime=` | 清理（返回删除数） | ADMIN |

**实体 SysAuditLog**：`id, userId, username, operation, ip, detail, createTime`

**页面特点**：只读（无行操作按钮），仅清理弹窗需要二次确认。时间参数 `yyyy-MM-dd HH:mm:ss`。`operation` 常见值：`LOGIN_SUCCESS/LOGIN_FAIL/CREATE_USER`。

## 7. 工程规则

- **API 层**：`import request from '@/utils/request'`，命名 `getXxxPage/createXxx/updateXxx/deleteXxx`，路径不含 `/api`
- **组件拆分**：每页拆 `XxxFilter.vue` / `XxxTable.vue` / `XxxFormDialog.vue`，放 `components/<page>/`
- **菜单接入**：`layout/index.vue` 加 `<el-menu-item index="/path">`，图标从 `@element-plus/icons-vue`
- **路由接入**：`router/index.js` 的 `children` 加懒加载路由
- **提交粒度**：每完成一个页面（含 api+components+view+路由+菜单）提交一次
